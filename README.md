# Uangku

Aplikasi pencatatan keuangan pribadi sederhana berbahasa Indonesia.

## Fitur
- Mencatat **UANG MASUK** dan **UANG KELUAR**.
- Saldo otomatis dari seluruh pemasukan dikurangi seluruh pengeluaran.
- Ringkasan uang masuk dan uang keluar bulan berjalan.
- Tanggal transaksi dapat diubah; catatan opsional.
- Mengubah dan menghapus transaksi.
- Penyimpanan lokal menggunakan IndexedDB.
- Dapat dibuka offline setelah pertama kali dimuat online.
- Cadangkan dan pulihkan catatan melalui file JSON.

## Privasi dan penyimpanan
Catatan transaksi tidak dikirim ke server dan tidak disinkronkan ke cloud. Data tersimpan di browser/perangkat yang digunakan. Menghapus data situs atau mengganti perangkat dapat menghilangkan data lokal. Gunakan **Cadangkan data** secara berkala.

## Publikasi GitHub Pages
1. Buka **Settings** repositori.
2. Pilih **Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch **main** dan folder **/(root)**, lalu tekan **Save**.
5. Tunggu publikasi selesai. GitHub akan menampilkan alamat situs pada halaman Pages.

## Instalasi Android
1. Buka alamat GitHub Pages menggunakan Chrome di Android.
2. Muat situs sekali saat internet tersedia.
3. Buka menu Chrome (⋮), lalu pilih **Tambahkan ke layar utama** atau **Instal aplikasi** jika tersedia.

Tahap ini adalah PWA yang dapat dipasang dari browser, bukan berkas APK Android.
